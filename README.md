# job-position-skills

## 岗位速懂

岗位速懂是一个帮助用户快速了解私企 / 体制外岗位的 AI Skill。

它适合大学生、研究生海投找实习/找工作，在时间非常有限的情况下快速了解某个岗位：

- 日常工作内容
- 所在业务链路
- 企业通常看重的能力
- 简历表达方式
- 面试准备方向

## 使用场景

当你想问：

- 这个岗位到底是干什么的？
- 这个岗位在业务里负责哪一环？
- 面试官可能会问什么？
- 我的经历怎么往这个岗位上靠？
- 我明天面试，怎么快速理解这个岗位？

可以使用这个 Skill。
