# interesting-skills

这个仓库用于存放一些有趣、实用的 AI Skill。

## 已收录 Skill

### 岗位速懂

岗位速懂是一个帮助用户快速了解私企 / 体制外岗位的 AI Skill。

它适合大学生、研究生、校招生、实习求职者、转行者，在时间有限的情况下快速了解某个岗位：

- 真实工作内容
- 所在业务链路
- 日常工作方式
- 企业通常看重的能力
- 简历表达方式
- 面试准备方向

## 使用场景

当你想问：

- 这个岗位到底是干什么的？
- 这个岗位每天真实工作是什么？
- 这个岗位在业务里负责哪一环？
- 面试官可能会问什么？
- 我的经历怎么往这个岗位上靠？
- 我明天面试，怎么快速理解这个岗位？

可以使用这个 Skill。
